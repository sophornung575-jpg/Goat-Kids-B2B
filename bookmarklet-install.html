🏷️ Restock tool bookmarklets

Two small browser buttons. Drag either one to your bookmarks bar. Both only ever touch your own catalog in Firestore — nothing is shared with anyone.

📥 Save a shop/search page

Click while browsing any 1688 shop or search results page (logged in as yourself) — saves every product visible on screen into your Home catalog.

📥 Save page to Goat Kids catalog

🖼️ Fill in a product photo

Click while viewing one specific product's own page on 1688 (a page whose link looks like detail.1688.com/offer/123...html) — grabs that page's main photo and saves it onto the matching catalog item. Useful for items imported from an order-history file, which never include photos.

🖼️ Save photo to Goat Kids catalog
Setup (desktop browser, one time):
  1. Make sure your bookmarks bar is showing (in Chrome: Ctrl/Cmd + Shift + B).
  2. Drag either blue/green button above up into your bookmarks bar, then let go. Repeat for the other one if you want both.
  3. Done — each is saved as its own bookmark.
Using the photo one, specifically:
  1. Open the catalog item's "View on 1688" link (or go to the product directly) so you're on that exact product's own page — not a shop or search page.
  2. Let the page fully load, including its main image.
  3. Click the green bookmark. It reads the offer ID straight from the page's own URL, so it always updates the right catalog item.
  4. Repeat for each product you want a photo for — one click each.
Heads up: I couldn't test either of these against 1688's real pages myself — their pages only fully render after JavaScript runs, which I can't execute from here, and their server blocks direct automated fetches too. The photo one picks the largest real image on the page, which is usually the main product photo, but if it grabs the wrong image or says it can't find one, tell me exactly what happened and I'll adjust it.
